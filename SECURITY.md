# Security policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report them privately through GitHub: go to the
[Security tab](https://github.com/schnaq/mattermost-plugin-meet/security/advisories/new) of this repository
and choose "Report a vulnerability". Include the plugin version, your Mattermost version and steps to
reproduce.

We aim to acknowledge a report within a few days and to publish a fix and an advisory once the issue is
resolved. If you run a deployment, also read the security notes in [docs/google-setup.md](docs/google-setup.md#security-notes).
